# 11.11 progress overview

## Desktop app: English and Traditional Chinese

The desktop app now speaks English and Traditional Chinese, and opens in Traditional Chinese unless the operator (or the computer's language) says otherwise. Decision and design are in `DECISIONS.md` ADR-171.

**What works.** A language switch in the sidebar, on Settings, and on the sign-in screen; it changes the screen in place and is remembered after a restart. The menu-bar (tray) menu, the file picker and the settings error messages follow it too. A test fails if a string exists in one language and not the other.

**Checked.** `npm test` (lint, the IPC contract check and the new language tests) passes. The app was run with `npm run dev` against a throwaway profile with fake cameras and no network, and every main screen was captured in both languages over the debugging port; the choice survived a restart.

**Not done / not verified.**
- The Chinese was written by the model; nobody who reads Chinese for a living has been through it yet.
- The tray menu was checked by unit test only (this machine's desktop shows no tray); it has not been seen on a Mac menu bar.
- Camera names, what the operator types, and the Log's entries are deliberately not translated.
- Nothing is pushed or released. This changes only the desktop app (not the pod code), so it does not go through pipeline staging; a desktop release candidate still needs its installed-build smoke check.
