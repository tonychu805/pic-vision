# 10.02 progress overview

## SDLC delivery-gate policy recorded

A review of this repository's git history found that the main process risk is not poor commit descriptions or absent incident analysis; it is that direct-to-`main` changes and release tags can precede a consistent, independent pre-merge and pre-release quality gate. Repeated history examples include defects first found in installed or live operation despite passing narrower checks.

Recorded ADR-150 and added the operational rule to `CLAUDE.md`: develop changes on short-lived branches, merge through a PR with verification/rollout/rollback evidence, run required CI on proposed changes and `main`, test a release candidate artifact before publication, and promote that exact artifact. Incidents should create an automated regression gate where practical.

**CI implementation prepared:** `Python tests` runs `make test` on every PR to and push to `main`; the macOS desktop workflow now runs its full test/package/bundle check on every PR to and push to `main`, while only a `desktop-v*` tag uploads and publishes a DMG. The desktop suite passed locally (306 tests); the local Python environment lacks `pytest`, so its new workflow has not yet been exercised remotely.

**First CI run found and corrected a false gate:** the real libx264 benchmark completed on GitHub's shared macOS runner at 0.43× realtime, but the test treated its own runner-capacity guess (`>0.5×`) as a correctness assertion. The test now requires a real, positive measurement; the product's 1.5× venue-suitability threshold remains in `MIN_USABLE_MULTIPLIER` and is evaluated on the actual venue machine. This keeps the check meaningful without making it flaky on unrelated CI capacity.

**Still required:** merge these workflow changes through a PR, then configure GitHub branch protection to require `Python tests / make test` and `Desktop CI and release (macOS) / build (arm64)` before merges to `main`. GitHub authentication from this workspace is currently invalid, so the remote PR and branch-protection setting cannot be made until it is refreshed.
