# 10.09 progress overview

## End-of-day local source retention (ADR-152) — built on branches, not deployed

Local recording retention now changes from 7 days after a reel / 30 days without one to: delete at the venue-local end of the day the recording ends when its reel is ready; otherwise retain only until the reel succeeds, then delete promptly. The desktop uses the venue timezone returned by the console and fails safe (keeps footage) when it cannot establish one.

The main and sub-stream folders are deleted as one unit. The existing dual-stream retention correction is included. Desktop reports only an aggregate local-source state in its heartbeat, and the console stores/displays it on the camera detail panel; no local path, filename, player data, booking data, or segment inventory crosses the machine boundary.

Focused retention tests: 13 passing; 41 targeted desktop tests (retention, cloud, IPC and store guards): passing. Desktop lint and production renderer build: passing. Console TypeScript: clean.
