# 09.26 progress overview

## Frame rate: 30 is now a target, not a hard requirement (not yet released)

At PGC on 09.25, a camera set to 30fps read 28 at 20:00, and the desktop refused to start that hour's scheduled recording, so the hour was lost. Changed at the operator's request (ADR-131):
- **29fps or above:** records as before.
- **25–28fps:** **records anyway**, with a warning in the desktop Log and the console's camera panel saying to set the camera back to 30.
- **Below 25fps:** refused, as before.

Only 30fps and 15fps (half the rallies) have ever been measured. How much 25–28 costs is unknown.

Tested: desktop 252, Python 245, console typecheck. **Not live yet:** the desktop change needs a new release, and the console and cloud-processing changes go live when pushed.
