# 10.30 progress overview

## Badge pose speed experiments

Tested pose batches 8/16/32, reduced input size, and YOLOv8n on the RTX 2000 Ada. Batch 16 did not materially speed up inference; batch 32 was slower. YOLOv8n was much faster but changed pose and badge measurements substantially. A full blind 42-rally brickwall comparison of YOLOv8x at 640×1120 showed an approximately 27% pose-time saving, but changed two of three awarded badge locations and added a different badge. Keep production at YOLOv8x 736×1280, batch 8; the reduced input is not acceptable for current badge behavior (ADR-163).

The full comparison is recorded in `EXPERIMENTS.md`; see ADR-161 through ADR-163 for the decisions and evidence.

### Staging speed trial in progress

Prepare a staging-only YOLOv8n-pose swap at 736×1280 to measure actual RunPod time while changing only the model size. The local seven-rally benchmark measured about 4.3× throughput, with noticeable pose-measure drift; the cloud run should report both runtime and badge results before any production decision. Production remains YOLOv8x at 736×1280, batch 8 while the staging result is reviewed.
