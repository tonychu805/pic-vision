# 2026-10-13 progress overview

## Pause rule on fresh sessions: it flagged nothing

**What was tested.** The "pause between rallies" rule (a rally is practice-like when it is followed AND preceded by a gap of 6 seconds or less) was the first rule in this investigation that removed practice at almost no cost, but only on the clips it was fitted on. Today it was run on 8 unseen PGC segments (68 detected rallies).

**What happened.** It flagged none of them, so the pre-registered check cannot be scored. The gap code itself is fine (on the fitted sessions it flags about 9% of rallies). Either these sessions hold little practice, or the rule does not hold up outside the sample. We cannot tell which yet.

**What it means for next steps.** Do not put the rule into ranking. A 30-clip sample (10 near-misses + 20 random unflagged) is cut for you to judge; how many of the 20 random are practice answers the question. Nothing shipped, nothing changed in production.

**Also discussed, not decided.** Using a vision model (Gemini or a local one) to veto candidates after TrackNet: ball machine / drill vs. play / "is a real exchange present". First step would be reproducing the old encoding-sensitivity problem (ADR-085) on ~20 judged clips. Open: whether field-test footage may be sent to an API at all (consent) or a local model should be used.
